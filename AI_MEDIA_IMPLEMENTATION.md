# GameVortex AI Media

External external media provider and external video provider media providers are intentionally disabled in this release.

- No `external media provider_KEY` is required.
- No `external video provider_API_KEY` is required.
- The main GameVortex AI chat is independent from these providers.
- The wallpaper system, FREE/VIP access, favorites, moderation, and downloads do not depend on external AI media providers.

The media database structures remain isolated so a future provider can be added without changing the core wallpaper system.
