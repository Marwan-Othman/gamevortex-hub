## Current safety boundary

The live flag remains disabled. No production live-order route or production executor is wired to call the adapter yet.

The project is intentionally **not** ready to submit real-money orders yet because the adapter still needs to be connected to the durable live-order state service, protected-exit submission/verification must be integrated into the fill workflow, settlement verification, emergency-stop handling, complete transactional audit coverage, controlled reconciliation/failure tests, and a controlled first-live-order procedure are still outstanding.

## Next implementation stage

Connect the fail-closed production adapter to the durable live-order state service without enabling the live flag. The executor must create the local intent first, transition through guarded states, reconcile provider responses by client order id, submit the protected OCO only after a confirmed fill, and enter `UNKNOWN` on any ambiguous provider response until provider state is reconciled.
