## Current safety boundary

The live flag remains disabled. No production live-order endpoint or production exchange adapter has been added.

The project is intentionally **not** ready to submit real-money orders yet because the live execution layer still needs protected exit orders, production adapter integration, settlement verification, emergency-stop handling, complete transactional audit coverage, and a controlled first-live-order procedure.
