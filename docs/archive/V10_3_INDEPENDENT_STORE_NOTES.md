# GameVortex Hub V10.3 — Independent Store Direction

- Added an original GameVortex visual direction rather than copying a marketplace layout.
- Added independent store taxonomy: game keys, gift cards, top-ups, DLC, subscriptions and digital items.
- Added region/country/denomination/delivery/provider verification fields to GameProduct.
- Added independent VIP tiers, referral tracking and raffle/draw models.
- Added dedicated Rewards, Referrals and Draws pages.
- Kept payment, supplier, top-up and delivery integrations disabled until real server-side providers are configured.
- No third-party marketplace identity, branding, catalog, or UI is required for GameVortex to operate.
