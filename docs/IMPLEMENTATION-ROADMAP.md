# Merged Implementation Roadmap

## Phase 0 — Baseline
- Preserve current code and data.
- Treat the production specification as the source of truth.
- Mark unsupported integrations as NOT_CONFIGURED/NEEDS_INTEGRATION.

## Phase 1 — Core production foundation
1. Real Authentication/session provider.
2. RBAC: SUPER_ADMIN / STAFF / USER.
3. Middleware and authorization.
4. Database migrations and indexes.
5. Audit logging and idempotency.
6. Error handling, rate limiting and validation.

## Phase 2 — Marketplace
1. Games + Apps catalog.
2. Real source verification.
3. Game details/media/platform mapping.
4. Reviews and moderation.
5. Download authorization.
6. Payments and purchases.
7. Gift cards with real provider/inventory.

## Phase 3 — Wallet/financial
1. User wallet.
2. Owner revenue ledger.
3. Owner points.
4. Owner withdrawal reservation.
5. Real payout provider.
6. Confirmation/reconciliation/refund/chargeback.

## Phase 4 — Gaming Tracker
1. Favorites.
2. Wishlist.
3. Recently viewed.
4. Personal/public collections.
5. Gamer profiles.
6. Follow/followers.
7. Activity feed.
8. Achievements/badges/XP/statistics.
9. Social notifications.

## Phase 5 — Discovery
1. Smart search.
2. Recommendations.
3. Deal radar.
4. Price history.
5. Steam import when configured.

## Phase 6 — Quran
1. Global mini player.
2. Expanded player.
3. Surah/reciter pages.
4. Last played/favorites.
5. Provider health/license management.

## Phase 7 — AI
1. AI Assistant.
2. AI Search.
3. AI Recommendations.
4. AI Discovery.
5. AI Moderation.
6. Admin AI analytics.
7. Prompt/tool injection controls and cost limits.

## Phase 8 — UX/quality
1. 3D Glass ecosystem.
2. Background/Animation/Glow/Theme controllers.
3. Mobile/Tablet UX.
4. Accessibility.
5. SEO.
6. Performance/caching.
7. Security audit.
8. Regression and final QA.
